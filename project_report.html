1. Executive Summary

AuraFin is an intelligent, responsive personal finance and wealth management platform designed to help users monitor cash flows, evaluate financial health scores, track milestone savings goals, and receive instant AI-driven financial advisory. Built with modular web architecture and high-contrast solid corporate styling, AuraFin provides an accessible, low-latency financial planning interface.

2. Key Features & Core Functionality

  • Financial Overview Dashboard: Real-time tracking of Monthly Income, Total Expenses, Net Monthly Surplus, and an automated 0–100 Financial Health Index calculation.
  • Interactive Budget Recalculator: Dynamic state update engine that recalculates savings rates, expense ratios, and financial health scores upon input modification.
  • AI Financial Adviser Engine: Interactive chat interface providing instant structured guidance on budgeting strategies (50/30/20 rule), emergency funds, debt payoff models (Avalanche vs. Snowball), and investment fundamentals.
  • Custom Gemini API Integration: Support for user-provided Google Gemini API keys via a dedicated Settings modal, with a built-in local financial intelligence engine fallback.
  • Capital Reserve Goal Tracker: Custom savings milestone management featuring dynamic progress bars and percentage completion tracking.
  • 50/30/20 Capital Distribution Planner: Automatic benchmark allocation for Fixed Needs (50%), Discretionary Wants (30%), and Wealth Accumulation (20%).

3. System Architecture & UI Design System

Design Philosophy & Standards

AuraFin adheres to modern corporate fintech aesthetics (inspired by platforms like Stripe and Ramp). It avoids tacky gradients and backdrop blurs in favor of 100% solid color surfaces, 2px crisp borders, DM Sans typography, and Font Awesome vector icons for maximum legibility and professional evaluation.
