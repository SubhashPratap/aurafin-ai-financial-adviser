A modern, responsive web application for personal wealth management, budgeting analysis, savings goal tracking, and AI-driven financial advice.

## 🌟 Key Features

1. **Financial Overview Dashboard**:
   - Live net cash flow metrics (Income, Expenses, Net Monthly Surplus).
   - Automated Financial Health Index rating score (0–100/100).
   - Interactive budget calculator with real-time health score updates.

2. **AI Financial Adviser Chat**:
   - Intelligent financial guidance covering budgeting strategies (50/30/20), emergency fund targets, debt payoff models (Avalanche vs. Snowball), and beginner investment principles.
   - Quick-action suggestion chips for common financial queries.
   - Support for custom **Google Gemini API Key** integration via Settings modal.

3. **Capital Reserve Savings Goals**:
   - Add and track progress toward custom financial milestones (e.g., Emergency Fund, Car Replacement, Property Down Payment).
   - Visual percentage progress indicators for target goals.

4. **50/30/20 Capital Distribution Framework**:
   - Automated breakdown of monthly income into Fixed Needs (50%), Discretionary Wants (30%), and Wealth Accumulation (20%).

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3 (Custom 100% Solid Theme System), Vanilla JavaScript (ES6+).
- **Icons**: Font Awesome 6 Free Vector Icon Library.
- **Typography**: DM Sans (Google Fonts).
- **API Integration**: Google Gemini Generative AI API (with local offline fallback engine).

## 🚀 How to Run Locally

### Method 1: Direct File Access
Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave).

### Method 2: Local HTTP Server
Run a local Web Server using Python or Node.js:

```bash
# Using Python:
python -m http.server 8080

# Using Node / npx:
npx serve .
```

Open `http://localhost:8080` in your web browser.
